Z2 Watch Data

Sleep, Nightly Recharge, daily activity, exercise, and heart rate recorded with Polar Vantage V2 watches. For the interpretation of the variables, consult Polar’s webpages and white papers.
Author

Maik Bieleke et al.

Published

20 November, 2026

Overview

The watch data were recorded with Polar Vantage V2 watches over the whole study and retrieved via the Polar AccessLink API v3.

Test phases: none. Use date to link the watch data to the study schedule (see Linking datasets).

Dataset names

All dataset names start with the project code pol. For sleep, recharge, and exercise, the content code combines the topic and the data type.

Part Code Meaning
Topic sl Sleep
Topic rc Nightly Recharge
Topic ex Exercise
Data type s Summary
Data type g Hypnogram (sleep stages)
Data type h Heart rate
Data type v Heart rate variability
Data type b Breathing rate
Data type z Heart rate zones
Data type r R-R intervals
Content act Daily activity
Content stp Steps
Content zon Activity zones
Content hrt Continuous heart rate

Variable names

Variable names start with a topic prefix followed by the measure. The IDs ad (daily activity) and ed (exercise session) are study-generated hashes of the Polar IDs and link the summary and sample datasets.

Prefix Topic Example
sl Sleep sldur
rc Nightly Recharge rchrvavg
ac Daily activity acsteps
ex Exercise exhravg
hr Continuous heart rate hrbpm
