A1 Fitness

Physical performance tests in the laboratory (body measures, resting cardiovascular values, balance, gait, stair climbing, strength, countermovement jumps, hopping, and a maximal exercise test) and training volume during the intervention.
Author

Maik Bieleke et al.

Published

20 November, 2026

Overview

The fitness data come from physical performance tests in the laboratory.

Test phases: p1 (pre), p2 (post), p3 (follow-up). See the study timeline.

Dataset names

The dataset name starts with the project code fit.

Code Meaning
tst Physical performance tests

Variable names

Variable names combine the test, the measure, and where needed a statistic, e.g. cmjpmax for the maximal power in the countermovement jump. The most common parts are:

Part Meaning
cmj, hop, bal, step, stair Countermovement jump, hopping, balance, gait, stair climbing
iso, mvc Strength on the IsoMed, maximal voluntary contraction
hr, bp, load, vo2 Heart rate, blood pressure, load, oxygen uptake
train Training volume
f, p, h, ct, ft, rsi Force, power, jump height, contact time, flight time, reactive strength index
fv0, range, brakedur, updur Force at zero velocity, upward movement range, braking duration, upward movement duration
max, rel, delta, total Maximum, relative to body mass, relative change, sum across zones
eo, z1 to z5 Eyes open, heart rate zones 1 to 5

Physical performance tests

Dataset fittsts, one row per participant and test phase (key: id, tp). It contains body measures, resting heart rate and blood pressure, balance, gait, stair climbing, strength, summary values of the countermovement jumps, hopping, the exercise test, variables relative to body mass, and the training volume per heart rate zone during the intervention (one value per participant, repeated in each test phase).
