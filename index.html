ProPELL Codebook

Documentation of all processed ProPELL datasets

Author

Maik Bieleke et al.

Published

20 November, 2026

ProPELL is a 21-week intensive longitudinal study with 75 participants (sport science students). It combines laboratory tests, MRI, saliva samples, online surveys, and recordings in daily life with activity sensors, smartphones, and watches. This site documents the processed datasets, with one codebook per project. This page explains what all codebooks have in common.

Codebooks

Codebook Project code Data
A1 Fitness fit Physical performance tests in the laboratory
A2 Cortisol cor Salivary cortisol after awakening and a morning questionnaire
B1 Effort eff Baseline, choice, and interval tasks on a cycle ergometer, with fNIRS
B2 Regulation reg Brain data (MRI) and performance in five tasks
B3 Ambulatory Assessment amb Physical activity (movisens Move 3) and smartphone surveys (movisensXS) in daily life
Z1 Surveys svy Screening, demographics, trait and state questionnaires
Z2 Watch Data pol Sleep, Nightly Recharge, daily activity, exercise, and heart rate

Study design

The study started with an online screening, followed by test phases before the training (pre), after the training (post), and at follow-up. Participants also completed weekly surveys. The variable tp gives the test phase or study week and uses the same codes in all codebooks. Not every project measured in every phase.

Code Meaning Study week Codebooks
p0 Screening Before the study Z1
p1 Pre TODO A1, A2, B1, B2, B3, Z1
p2 Post TODO A1, A2, B1, B2, B3, Z1
p3 Follow-up TODO A1, A2, B1, B3, Z1
w02 to w21 Weekly survey 2 to 21 Z1

There was no weekly measurement in week 1, so the weekly codes start at w02. The watch data (Z2) have no test phase because they are collected continuously throughout the study (see Linking datasets).

Dataset names

Every dataset name has seven letters: a project code (three letters), a content code (three letters), and a level code (one letter) that says what one row is. For example, corcare stands for cortisol (cor), cortisol awakening response (car), and one row per event (e). The project codes are listed under Codebooks, the content codes in each codebook. Some projects split the content code into a topic or task and a data type, such as ch (choice task) and p (performance) in effchps.

Level code One row is Example
p Participant svyscrp
s Test phase or study week fittsts
d Day or night ambactd
e Event within a day, such as a sampling point, a prompt, or an exercise session corcare
h Hour polstph
m Minute, or a time step of 1 to 5 minutes ambactm
t Trial or block regespt
c Continuous signal (seconds or finer, or beat to beat) effchfc

Variable names

Repeated measurements are stored in rows. A variable has the same name in every test phase, and tp says which test phase a row belongs to.

Questionnaire variables follow the same rules in all projects:

Pattern Meaning Example
Scale and two-digit number Item bscs01, aff01
Scale Scale score bscs
Scale and one letter Subscale score proei, affv
Item and d Free-text detail to that item consumption01d

All other variables combine building blocks that are explained in each codebook, for example cmjpmax (maximal power in the countermovement jump) in A1.

Linking datasets

Each participant has the same anonymized ID, id, in every dataset that contains IDs. The test phase tp uses the same codes in all codebooks, so id and tp link datasets across projects. Within a project, datasets of different levels share the variables of their keys, for example the exercise ID ed in the watch data.

The watch data (Z2) have no test phase. Use date to link them to the study schedule.

The admission checklist and the demographics (Z1) are not linked to participant IDs for privacy reasons, so they cannot be combined with other datasets.

Reading a codebook

Each codebook has the same structure:

  • Overview: how the data were collected, which test phases are included, and a table of the project’s datasets. The table shows what one row is, the key (the variables that together identify one row), and the number of rows and variables.
  • Dataset names and Variable names: the codes used only in this project.
  • One section per dataset: every variable with its label, details, units, response options, descriptive statistics, and distribution.

Use the search in the navigation bar to find a variable by its name or label.
