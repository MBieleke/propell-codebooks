B2 Regulation

MRI data: brain data (ROI eigenvariates) and task performance in five tasks (emotion regulation, emotional Stroop, go/nogo, n-back, task switching).
Author

Maik Bieleke et al.

Published

20 November, 2026

Overview

The regulation data contain brain data and task performance from five tasks in the MRI scanner.

Test phases: p1 (pre), p2 (post). See the study timeline.

Dataset names

All dataset names start with the project code reg. The content code combines the task and the data type.

Part Code Meaning
Task er Emotion regulation
Task es Emotional Stroop
Task gn Go/nogo
Task nb N-back
Task ts Task switching
Data type b Brain data (ROI eigenvariates)
Data type p Performance

Variable names

Brain data have one column per region of interest (ROI), named with a three letter abbreviation. Performance measures use a short prefix or suffix.

Building block Meaning Example
ROI (3 letters) Eigenvariate of a region of interest amy, dlp
avg Mean across trials or blocks rtavg, valavg
n Number of responses of one kind ncor, nmis
rt Response time rt, rtavg
val, aro, dom Valence, arousal, dominance rating val

Codes of condition and response differ between tasks and are listed in each task section.
