B1 Effort

Laboratory sessions on a cycle ergometer: session setup and questionnaires, performance in a baseline, choice, and interval task, and fNIRS recorded during the choice and interval tasks.
Author

Maik Bieleke et al.

Published

20 November, 2026

Overview

The effort data come from laboratory sessions on a cycle ergometer with a baseline task, a choice task, and an interval task, recorded together with fNIRS. There was one session per test phase.

Test phases: p1 (pre), p2 (post), p3 (follow-up). See the study timeline.

Dataset names

All dataset names start with the project code eff. For the tasks, the content code combines the task and the data type.
